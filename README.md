# Dick Riders Movie Wheel

Колесо выбора фильма для команды Dick Riders. Интерфейс на русском.

## Запуск

Установите Node.js, откройте терминал в папке проекта и выполните:

```sh
node work/static-server.mjs
```

Откройте http://127.0.0.1:4173/ в браузере. Для остановки сервера нажмите Ctrl+C в терминале.

## Возможности

- Добавление фильмов вручную и импорт из .docx или .txt.
- Обычный выбор и режим на выбывание.
- Время вращения от 2 до 60 секунд.
- Сохранение списка и настроек в браузере.

Для импорта Word нужен запущенный сервер. Старый формат .doc не поддерживается.
Данные браузера не входят в Git-репозиторий и не синхронизируются между друзьями.

## Структура

- outputs/ — интерфейс сайта.
- work/static-server.mjs — локальный сервер и обработчик импорта Word.
- work/test-docx-import.mjs — проверка импорта при запущенном сервере.
